# Проект «Малые кадры»

## Архитектура

- C++20.
- GUI: Qt6 Widgets.
- База данных: SQLite через Qt6 Sql.
- core/ — чистый C++ без Qt, SQLite, файлов, сети и GUI.
- storage/ — только работа с SQLite и преобразование данных.
- gui/ — только интерфейс, ввод и отображение.
- Все расчётные правила находятся в core/.
- Не расширять область задачи без явного указания.

## Денежные значения

- Деньги хранятся только в копейках через int64_t.
- float и double для денег запрещены.
- Рациональная арифметика должна быть точной.
- Округление half-up выполняется от нуля и один раз в конце расчётной позиции.
- Деление на ноль и переполнение должны выдавать исключение.

## Даты

- В core даты представлены собственным типом Date.
- Нельзя использовать QDate, QDateTime, time_t, localtime или mktime в core.

## Стиль

- Файлы и функции: snake_case.
- Типы: PascalCase.
- enum class с явными числовыми кодами.
- Не использовать using namespace std.
- Не добавлять лишние абстракции.
- Не менять тесты, чтобы скрыть ошибку реализации.
- После изменений запускать run_tests.bat.

## Тестирование

- Каждый модуль должен иметь тесты.
- Ошибка теста должна возвращать ненулевой exit code.
- Новые тесты размещать в core/tests/*_tests.cpp.
- Сначала сообщить план изменений, затем изменить файлы и запустить тесты.
